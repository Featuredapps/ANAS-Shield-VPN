# ANAS // SHIELD VPN — Android

مشروع Android Studio (Kotlin) يحافظ على واجهة HTML الأصلية داخل WebView ويضيف محرك WireGuard الرسمي عبر مكتبة `com.wireguard.android:tunnel`.

## البناء
1. افتح المجلد في Android Studio حديث.
2. استخدم JDK 17 وثبّت Android SDK Platform 35.
3. نفّذ Sync Gradle ثم Build > Build APK(s).
4. ثبّت APK على الهاتف.

## التشغيل
- استورد ملف إعداد WireGuard بصيغة `.conf` من مزود VPN أو من خادم WireGuard تملكه.
- اضغط اتصال ووافق على نافذة إذن VPN من أندرويد.
- لا توجد خوادم مجانية مضمّنة. أسماء النطاقات والمفاتيح الواردة في التصميم الأصلي بيانات تجريبية وغير قابلة للاستخدام.
- يجب أن يكون المفتاح العام مطابقاً للمفتاح الخاص ومسجلاً على الخادم.

## حدود النسخة
- اتصال WireGuard حقيقي عند استيراد ملف صحيح.
- خيارات Stealth TLS وOpenVPN في التصميم الأصلي واجهة شكلية وغير مفعّلة.
- تقسيم التطبيقات، قاطع الاتصال، حجب الإعلانات وقياسات السرعة تحتاج تطويراً أصلياً إضافياً.
- هذه الحزمة لا تتضمن APK مبنياً؛ يتطلب البناء تنزيل اعتماد WireGuard من Maven.

## بناء APK تلقائياً عبر GitHub Actions
بعد رفع المشروع إلى فرع `main`، سيبدأ البناء تلقائياً عند كل Push، ويمكن تشغيله يدوياً من تبويب Actions. بعد نجاح البناء نزّل `ANAS-SHIELD-VPN-debug-apk` من Artifacts. الناتج APK تجريبي بمفتاح debug وليس إصداراً إنتاجياً للنشر.
