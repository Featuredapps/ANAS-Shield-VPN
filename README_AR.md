# ANAS // SHIELD VPN — Android

مشروع Android Studio (Kotlin) يحافظ على واجهة HTML داخل WebView ويضيف محرك WireGuard عبر مكتبة `com.wireguard.android:tunnel`.

## البناء
1. افتح المجلد في Android Studio حديث.
2. استخدم JDK 17 وثبّت Android SDK Platform 35.
3. نفّذ Sync Gradle ثم Build > Build APK(s).
4. ثبّت APK على الهاتف.

## التشغيل الحالي
- اتصال WireGuard متاح عند استيراد ملف إعداد WireGuard بصيغة `.conf` صالح من مزود VPN أو من خادم تملكه.
- اضغط اتصال ووافق على إذن VPN من أندرويد.
- التطبيق يجلب قائمة خوادم عامة من VPN Gate لعرضها واختيارها.
- **اختيار خادم VPN Gate لا ينشئ اتصالاً حالياً**: هذه الخوادم تقدم ملفات OpenVPN، بينما محرك OpenVPN لم يُدمج بعد.
- خوادم VPN Gate يشغلها متطوعون مستقلون؛ لا يملك المشروع هذه الخوادم ولا يضمن توفرها أو سياسة تسجيلها أو خصوصيتها.

## حدود النسخة
- اتصال WireGuard حقيقي فقط مع ملف `.conf` صالح.
- خوادم VPN Gate ظاهرة في الدليل فقط، وليست قابلة للاتصال من التطبيق بعد.
- خيارات Stealth TLS وOpenVPN في التصميم الأصلي غير مفعّلة.
- تقسيم التطبيقات، قاطع الاتصال، حجب الإعلانات وقياسات السرعة تحتاج تطويراً أصلياً إضافياً.
- ملف APK التجريبي يُبنى عبر GitHub Actions، ولا يُعد إصداراً إنتاجياً.

بعد رفع المشروع إلى فرع `main`، يبدأ البناء تلقائياً عند كل Push، ويمكن تشغيله يدوياً من تبويب Actions. بعد نجاح البناء نزّل `ANAS-SHIELD-VPN-debug-apk` من Artifacts. الناتج APK تجريبي بمفتاح debug وليس إصداراً إنتاجياً للنشر.
